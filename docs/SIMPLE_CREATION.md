# 주제 하나로 제작 준비

`/create`에서 한국어 주제를 입력하면 45초 목표 프로젝트를 만들고 자료 조사 → 구성안 3개 → 첫 구성안 기본 선택 → 대본·장면 목록 생성을 순서대로 실행합니다. 기본 메뉴는 새 영상 만들기, 내 작업함, 기본 설정입니다. 기존 상세 도구는 펼쳐서 사용할 수 있습니다.

각 단계 결과는 DB에 저장합니다. 요청 응답을 받지 못해도 같은 생성 요청을 다시 보내면 같은 프로젝트를 반환합니다. 준비 단계는 프로젝트 단위 DB 잠금으로 중복 실행을 막으며, 저장된 결과가 있으면 재생성하지 않습니다. 화면을 닫으면 다음 단계 호출은 멈추고 내 작업함의 '자동 제작 이어서 진행'으로 돌아갈 수 있습니다. 전체 백그라운드 제작 큐는 아직 아닙니다.

## 실제 AI 설정

- APP_MODE=live와 기존 Supabase 로그인 설정 필요
- GEMINI_API_KEY, GEMINI_RESEARCH_MODEL, GEMINI_CONTENT_MODEL 필요
- 워크스페이스의 geminiResearch 기능 활성화 필요
- Demo에서는 외부 API 없이 예시 결과만 생성합니다.
- 대본 API는 https://ai.google.dev/api/generate-content 의 generateContent 계약을 사용합니다.
- API 키가 없거나 모델 응답이 형식/시간 규칙을 위반하면 실패를 표시합니다. Live에서 Mock으로 대체하지 않습니다.
- 모델의 사실 정확성, 예상 발화 시간, 성과 점수는 자동 검증된 사실이 아닙니다. 기존 출처 연결과 QA 및 사람의 검토가 필요합니다.

## 미완료 범위

Pexels 자동 수집, AI 비디오 생성, 음악 처리, YouTube OAuth 게시·예약, 상시 호스팅 배포는 이 변경에 포함되지 않습니다. 현재 합성 기능은 수동 클립/placeholder 기반입니다. 신규 화면은 이를 명시하며, 영상 완성이나 게시 완료로 표시하지 않습니다. 자동 준비는 최종 승인이나 게시를 실행하지 않습니다.

## 검증

단위 테스트에는 Live 응답 형식, 타임라인 겹침, CTA 길이, upstream 실패가 포함됩니다. HTTP smoke 검증은 실제 DB에서 생성 재시도, 순서 오류, 조사·구성·대본 저장, 재개 시 중복 방지 및 자동 승인 없음까지 검사합니다. 실제 Gemini 호출은 API 키가 제공된 배포 환경에서 별도 확인해야 합니다.

## 내레이션 연결 (추가)

Live 모드에서 GEMINI_API_KEY와 GEMINI_TTS_MODEL을 설정하면 대본 생성 뒤 Gemini TTS를 자동 실행합니다. GEMINI_TTS_VOICE 기본값은 Kore이며 모델은 명시적으로 지정해야 합니다. 대본 상세 화면에서도 생성 및 미리 듣기가 가능합니다. API 계약: https://ai.google.dev/api/generate-content#SpeechConfig

장면별 음성을 WAV로 저장하고 앞뒤 무음을 제거합니다. 1.3–1.5배속 범위에서 장면 길이에 맞추며 남는 구간은 무음으로 채웁니다. 1.5배속으로도 길이가 맞지 않으면 실패로 표시하고 대본 수정을 요청합니다. 문장 중간 무음 자동 제거 및 음성 인식 기반 자막 정렬은 아직 없습니다.

생성한 장면 음성을 파일로 캐시하여 재시도 시 재사용합니다. 외부 API 응답 직후 프로세스가 종료되면 중복 과금을 완전히 방지할 수는 없습니다. 모델명·음성·대본·시간으로 캐시를 구분합니다. 완성 내레이션은 DB media_assets에 저장되며 대본 또는 장면 시간이 바뀌면 이전 음성을 렌더에 사용하지 않습니다. 렌더는 음성 파일의 체크섬과 대본 지문을 확인합니다.

현재 준비 단계는 브라우저가 열려 있어야 다음 요청을 시작합니다. TTS는 장면당 최대 120초를 기다리므로 운영 프록시 타임아웃 설정이 필요합니다. API 비용은 제공자 사용량에 따르며 앱 내 비용 상한 차단은 아직 없습니다.

실제 계정으로 생성한 음성의 발음·품질 검증은 키 연결 후 필요합니다. 테스트는 합성 테스트 음원을 주입하며 실제 음성이나 외부 API 성공으로 취급하지 않습니다.
