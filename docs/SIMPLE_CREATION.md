# 주제 하나로 제작 준비

`/create`에서 한국어 주제를 입력하면 45초 목표 프로젝트를 만들고 자료 조사 → 구성안 3개 → 첫 구성안 기본 선택 → 대본·장면 목록 생성을 순서대로 실행합니다. 기본 메뉴는 새 영상 만들기, 내 작업함, 기본 설정입니다. 기존 상세 도구는 펼쳐서 사용할 수 있습니다.

각 단계 결과는 DB에 저장합니다. 요청 응답을 받지 못해도 같은 생성 요청을 다시 보내면 같은 프로젝트를 반환합니다. 준비 단계는 프로젝트 단위 DB 잠금으로 중복 실행을 막으며, 저장된 결과가 있으면 재생성하지 않습니다. 화면을 닫으면 다음 단계 호출은 멈추고 내 작업함의 '자동 제작 이어서 진행'으로 돌아갈 수 있습니다. 전체 백그라운드 제작 큐는 아직 아닙니다.

## 실제 AI 설정

- APP_MODE=live와 기존 Supabase 로그인 설정 필요
- GEMINI_API_KEY, GEMINI_RESEARCH_MODEL, GEMINI_CONTENT_MODEL 필요
- 워크스페이스의 geminiResearch 기능 활성화 필요
- Demo에서는 외부 API 없이 예시 결과만 생성합니다.
- 대본 API는 https://ai.google.dev/api/generate-content 의 generateContent 계약을 사용합니다.
- API 키가 없거나 모델 응답이 형식/시간 규칙을 위반하면 실패를 표시합니다. Live에서 Mock으로 대체하지 않습니다.
- 모델의 사실 정확성, 예상 발화 시간, 성과 점수는 자동 검증된 사실이 아닙니다. 기존 출처 연결과 QA 및 사람의 검토가 필요합니다.

## 미완료 범위

TTS, Pexels 자동 수집, AI 비디오 생성, 음악 처리, YouTube OAuth 게시·예약, 상시 호스팅 배포는 이 변경에 포함되지 않습니다. 현재 합성 기능은 수동 클립/placeholder 기반입니다. 신규 화면은 이를 명시하며, 영상 완성이나 게시 완료로 표시하지 않습니다. 자동 준비는 최종 승인이나 게시를 실행하지 않습니다.

## 검증

단위 테스트에는 Live 응답 형식, 타임라인 겹침, CTA 길이, upstream 실패가 포함됩니다. HTTP smoke 검증은 실제 DB에서 생성 재시도, 순서 오류, 조사·구성·대본 저장, 재개 시 중복 방지 및 자동 승인 없음까지 검사합니다. 실제 Gemini 호출은 API 키가 제공된 배포 환경에서 별도 확인해야 합니다.
